# averystoolbelt-media

Published media for Avery's Toolbelt social posts: the Shorts and post images only, so Buffer can fetch them by URL.
Plus `voice_bakeoff/`: the Track D voice bake-off clips (the same scene voiced three ways) for the owner to play on a phone; see avery_engine episodes/_voice_bakeoff/README.md. Plus `podcast/`: Avery's Story Time as a podcast (feed.xml, cover.jpg, one MP3 per new-voice story-time episode), generated by avery_engine `tools/codefilm/podcast_feed.py` - never hand-edited. Nothing else lives here. The show itself is on YouTube.
